# 場面整理テンプレート — 必要最小限

作成日: 2026-09-10
用途: 本文を自由に書きながら、確定した事実と未決定事項を混同しないためのメモ。

全場面について全欄を埋める義務はありません。該当しない項目は「なし」、決まっていない項目は「未決定」と書きます。整理のために対立、事件、人物、設定を新設しません。本文・台詞・比喩を固定する台本ではありません。

下の枠を必要な場面だけに使用します。作成した場面票は新作の資料として `main_novel/` 内に保存し、この空のテンプレートを作品固有の内容で上書きしません。

## 最小の場面メモ

### 対象と状態

- 対象本文・場面:
- 状態: 案 / 採用済み / 未決定を含む
- 根拠: 今回のユーザー指定、または新作内の該当資料
- 時間・場所・経過時間:
- 語り方・視点・切替の有無:
- 登場人物と、今ほしいもの・避けたいもの:

### この場面で維持する事実

- 開始状態: 直前から持ち込む身体、物、関係、未解決事項
- 知識と開示: 誰が何を知り、どう知ったか。読者に今回示す範囲
- 関係・呼称・感情の対象:
- 今回変えてはいけないこと / 未決定のこと:

### 場面の役割と出口

- 主な役割: 事件 / 関係 / 情報 / 生活時間 / 場所 / 余韻 / その他
- 起きる行動、またはそこで過ごす経験:
- 障害・選択: 実際にある場合だけ。なければ「なし」
- 結果・残る感覚・終了状態:
- 次へ持ち越すもの: 後続がない、または完結する場合はその旨
- 表現に委ねること: 言い回し、動作の細部、長短、間など

通信・配信が実際に登場する場合は、誰に何が見え聞こえするかと公開状態を追加します。権限・技術・設備が重要な場合も、その場面に必要な範囲だけ追加します。存在しない要素をテンプレートに合わせて作りません。

## 修正したときの記録

- 修正理由と分類:
- 変更した確定事項:
- 影響する本文・前後場面:
- 再確認した範囲 / 未確認の範囲:

表現のみの修正では確定事項を変えません。構造を変える場合は、場面票と影響する本文を揃え、古い理由や結果を残しません。
