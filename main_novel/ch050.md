# 第50話　だいたい勝ち、ではない

美月は、だいたい勝ち、と言えなかった。

銀色の軽自動車の若者は、スマホを下げない。

レンジは間に入っている。

助手はカメラを下ろしている。

棚は映っていない。

母屋も、まだ映っていない。

それでも、状況はもう勝ちではなかった。

「スマホを下げてください」

美月は言った。

声が少し硬い。

硬くてもいい。

痛くしない。

そう、昨日の配信で湊人は言った。

けれど、いま目の前にいる相手に、その加減が通じるかどうかはわからない。

若者は口を尖らせた。

「なんで？　公道ですよね」

「棚より奥を撮らないでください」

「だから、撮ってないって」

スマホのレンズは、門の方を向いている。

美月には、それが見える。

レンジにも見えている。

「君、ライブしてるか」

レンジが聞いた。

若者の目が一瞬泳いだ。

美月の胃が冷えた。

「してないっすよ」

「画面を見せろ」

「なんでレンジさんに見せなきゃいけないんですか」

レンジの顔が、完全に変わった。

怒鳴らない。

でも、さっきまでの動画向けの穏やかさが消えている。

「野口、車」

助手が動いた。

ワゴン車の位置を確認する。

狭い道だ。

銀色の軽自動車が詰めるように止まっているせいで、黒いワゴン車は出られない。

軽自動車が先に降りなければ、誰も撤収できない。

「車をどかせ」

レンジが若者に言った。

「いや、まだ」

「今すぐ」

「なんで」

「ここから出すためだ。君もだ」

若者は、そこで少し怯んだ。

美月は、ポケットの中で端末を握ったまま、門の内側を見ないようにした。

湊人が出てくる。

出てきてほしくない。

でも、出てきてほしい。

矛盾した願いが、胸の中でぶつかった。

コトハは母屋の奥にいる。

声は聞こえているかもしれない。

届いていないかもしれない。

わからない。

そのわからなさが怖い。

「白い子、いるんでしょ」

若者が言った。

軽い声だった。

見たいものの名前を、景品のように呼ぶ声だった。

美月の中で、何かが切れかけた。

「いません」

言い切る。

嘘かもしれない。

けれど、この場ではそれでいい。

若者は笑った。

「いるって聞いたけど」

「ここにいるのは野菜です」

「いや、そういうのいいんで」

その瞬間、母屋の戸が開いた。

大きな音ではない。

古い戸が、少しだけ軋む音。

それだけで、全員がそちらを見た。

湊人が出てきた。

地味な上着。

黒い髪。

目立つところは何もない。

けれど、美月にはすぐにわかった。

いつもの台所の湊人ではない。

背筋が、少し違う。

声を荒げる前の人ではない。

声を荒げずに終わらせると決めた人だった。

湊人は、まず美月を見た。

怪我がないか。

震えていないか。

それを一瞬で確かめた。

次にレンジを見る。

最後に若者のスマホを見た。

「撮影をやめてください」

湊人の声は低かった。

若者は、反射的にスマホを少し下げた。

「いや、誰ですか」

「この敷地の管理者です」

管理者。

湊人は、自分の名前を出さなかった。

美月は、その判断に少しだけ息を吐いた。

「棚以外の撮影は禁止です。人、母屋、門の内側、近隣、未成年に見える人物に関する撮影と質問も禁止です。続けるなら警察に連絡します」

「脅しですか」

「手順です」

湊人は即答した。

怒鳴らない。

言い返さない。

ただ、逃げ道を一つずつ塞ぐ。

「今、ライブ配信をしていますか」

若者は答えない。

湊人はレンジを見た。

レンジは短く言った。

「可能性があります。こちらの同行者ではありません」

「わかりました」

湊人は若者へ視線を戻す。

「配信中なら、今すぐ停止してください。停止確認後、車を移動してください。停止しない場合は、警察へ連絡します」

若者の口が動いた。

何か言い返そうとして、言葉にならない。

レンジが一歩横へ出た。

「車を出せ。俺の動画を見て来たなら、俺の前でこれ以上やるな」

若者は、ようやくスマホを下げた。

画面を操作する。

湊人は近づかない。

画面を覗き込まない。

覗けば、それもまた材料になる。

「停止しました」

若者が言った。

湊人は、美月へ視線を送った。

美月は、震える指で端末を操作した。

日下部への下書きだけ開く。

まだ送らない。

でも、送れる。

それだけで、少し息ができた。

若者はぶつぶつ言いながら軽自動車へ戻った。

エンジンがかかる。

狭い道を、乱暴に切り返す。

レンジの助手が道の端に立ち、誘導する。

若者の車が坂を下り始めるまで、誰も話さなかった。

銀色の車が見えなくなった後、レンジが深く頭を下げた。

「申し訳ありません。私の動画が呼びました」

湊人は、レンジを見た。

動画だけを見れば、迷惑系に見えた。

目の前のレンジは、想像以上に危うく、想像以下に雑ではなかった。

人は、動画だけでは判断できない。

だが、動画だけで人は来る。

美月の言葉が、湊人の中で重く残った。

「撤収してください」

湊人は言った。

「はい」

レンジはうなずいた。

「大根は」

美月が、思わず聞いた。

レンジは一瞬だけ迷い、それから料金箱の方を見た。

「置いていきます」

「買ったものは持って帰ってください」

美月の声は、少しだけ怒っていた。

「野菜は悪くないので」

レンジは、その言葉にもう一度頭を下げた。

大根を持ち、助手と一緒にワゴン車へ戻る。

黒い車が坂を下っていく。

残ったのは、棚と、少し乱れた砂利と、かぼちゃの丸い影だけだった。

美月は、ようやく息を吐いた。

「だいたい勝ち、じゃないね」

湊人は答えた。

「今日は、負けないで済んだだけだ」

美月は小さくうなずいた。

それでも、棚の小松菜を直した。

生活を戻すために。

まず、葉の向きを揃えた。
