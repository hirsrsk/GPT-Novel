# 第76話　戻った身体

点。

コトハの紙に、黒い点がある。

だめ。

湊人の指が止まった。

「医者がいない」

湊人は言った。

「はい」

茜が答える。

「反動がわからない」

「はい」

「死ぬかもしれない」

「はい」

返事はしている。

聞こえてもいる。

けれど、茜の目は台所の方へ向いている。

元以上かもしれない。

その言葉が、まだ消えていない。

「それでも」

「それでも」

湊人は台所へ戻った。

美月が「湊人さん」と呼んだ。

久我山が何か言いかけた。

ユラは、息もせずに見ている。

棚の奥に、小さな器がある。

コトハ用に、瘴気を落ち着かせてあった欠片。

米粒より小さい。

器を持つ指が冷たい。

鍋の粥が、静かに揺れている。

「半分以下」

湊人は自分に言った。

誰も返事をしない。

欠片を削る。

さらに削る。

皿の上に残ったのは、粉に近い欠片だった。

それでも、普通の人間に出すものではない。

湊人は鍋へ落とした。

湯気が折れた。

ユラが息を飲む。

「やっぱり」

その声で、湊人の手が止まる。

「黙っていてください」

美月が言った。

ユラは口を閉じた。

目だけが騒いでいる。

茜の前に、小さな椀が置かれた。

いつもの半分より少ない。

湊人は匙を渡さなかった。

自分で持った。

「一口だけです」

茜は頷いた。

「二口目はありません」

「はい」

「俺が止めます」

「はい」

湊人は匙を差し出す。

茜はそれを見た。

手袋のない指が、膝の上で震えている。

「自分で」

「駄目です」

「私の身体です」

「だから、俺が止めます」

茜は笑った。

痛そうな笑いだった。

「ひどい人」

「はい」

「でも、見て」

湊人は匙を差し出した。

茜が口を開ける。

食べる。

飲み込む。

数秒。

何も起きない。

久我山が息を止めている。

美月はコトハの前に立った。

ユラは、畳に爪を立てている。

茜が目を閉じた。

「痛くない」

声が落ちた。

「首が」

自分の首筋に触れる。

布が邪魔だった。

茜は布をほどいた。

黒ずんだ首筋が見える。

その黒が、灰色へ薄れていく。

「冷たい」

湊人は椀を下げた。

茜の手が伸びる。

弱い。

でも、退かない。

「もう一口」

「駄目です」

「お願い」

「駄目だ」

湊人は椀を遠ざけた。

茜は追わなかった。

追う前に、指が開いた。

曲がっていた関節が、ゆっくり伸びる。

爪の黒ずみが薄れていく。

片目の濁りが、瞬きのたびに薄くなる。

「見える」

茜が言った。

「ちゃんと、見える」

久我山が一歩出る。

茜は手で制した。

支えはいらない、とでも言うように。

立ち上がる。

ふらつく。

それでも、自分の足で立つ。

手袋を拾わない。

髪で顔を隠さない。

首の布も、畳の上に落ちたままだ。

肩の線が、呼吸に合わせて戻る。

腰の位置が変わる。

頬の歪みが消えきらないまま、血の色だけが先に差す。

美月が口元を押さえた。

「ユラ、離れて」

ユラは見ていた。

美月が肩を掴んでも、見ていた。

叩かれた頬を赤くしたまま。

瞬きも少なく。

茜は、湊人を見た。

胸の奥で、何かがずれた。

痛みが消えた場所へ、別の熱が入り込む。

理由はなかった。

さっきまで欲しかったのは、身体だった。

鏡を見られること。

立てること。

父の理由で終わらないこと。

それだけだった。

なのに、今は湊人から目が離れない。

「朝倉さん」

声が澄んでいる。

その声に、茜自身が少し震えた。

わからない。

これは感謝なのか。

痛みが引いた反動なのか。

身体が急に戻ったせいなのか。

何もわからない。

坂の下で車の音がした。

井坂の軽トラック。

美月が呼んだのだ。

湊人は、ようやく息をした。

椀を持つ手が、震えている。

鍋の湯気はまだ細く立っていた。

ユラだけが、その湯気を見ていた。

そこに残った、S級素材のほどけ方を。
