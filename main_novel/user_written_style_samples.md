# ユーザー原文・文体サンプル

作成日: 2026-07-06

このファイルは、ユーザー自身が書いた文章、またはユーザー原文を主軸にした箇所を後から判別するためのメモ。

本文をリライトする時は、ここに記録された箇所を優先的な文体サンプルとして扱う。GPT案やGPT補筆と混ざっている可能性がある本文については、ここで「ユーザー原文由来」と明記されている範囲を特に尊重する。

## 運用ルール

- ユーザーがチャットで本文を直接書いた場合、以後は可能な限りこのファイルへ追記する。
- 原文をそのまま保存できる場合は、引用ブロックで残す。
- すでに本文へ組み込まれている場合は、ファイル名と冒頭文で照合できるように残す。
- 「現在の本文全体がユーザー原文」という意味ではない。GPT補筆、整形、後続修正が混ざっている場合がある。
- 文体参照では、派手な言い換えより、視点、情報経路、人物の行動原理を優先する。

代表サンプル:


### `ch063.md` 神楽坂由良の世界

照合用冒頭:

```text
神楽坂由良の世界は線でできている。
```

ユーザー原文由来の中心:

- 由良には生まれた瞬間から線が見えている。
- 他の子供には線が見えないと幼いころに気づく。
- それが魔力と呼ばれるものだと思い至る。
- カメラ越しでも線が見える。
- 探索者の線は綺麗で、だから由良が探索者になるのは自明。
- 由良にとって魔法派かどうかは本質ではなく、他の人がそう呼ぶから魔法と呼んでいる。

文体上の特徴:

- 由良の異常性を、本人にとっての当然として書く。
- 善悪や倫理ではなく、見える、知りたい、近づきたいという認識で進む。
- 由良は患者、人間、娘といった社会的意味に興味を持たない。興味がないものは描写しない。

代表サンプル:

```text
神楽坂由良の世界は線でできている。

その線はどこにでもある。空気中にも机の上にも、天井の梁にも、自分の手のひらにでも。

生まれた瞬間から見えていた。それが由良の世界だった。
```

```text
由良にとってそれが魔法かどうかということは別にどうでもいい。他のみんなが魔法派と名乗っているから由良も魔法と呼んでいる。ただそれだけのことだ。
```

## 文体参照時の注意

- ユーザー原文は、短文があっても「GPT的な余韻のための短文連打」とは違う。視点人物の認識や状況の圧に沿って切れているかを見る。
- GPTが補筆する場合、意味を先に説明しない。
- 「〇〇ではない」「本当は〇〇」といった作者視点の否定から入らない。
- 一文だけ言い換えたあと、次の台詞や地の文が浮かないか確認する。
- 人物を聞き分けよくしない。特に由良は、理解しても止まらない。
- 湊人の飯は、相手にいちいち選ばせるものではない。黙って思いやって作る。
- 茜は大義より、生きたい、食べたい、眠りたい、戻りたいという執着を優先する。
- 水原は冷たい管理者ではない。本当に患者を治したい医者として扱う。
