# 第38話　朝の固定コメント

事故から十二日目の朝だった。

古民家に来てから、朝の数え方が少し変わった。

事故から何日目か。

コトハがどれだけ食べられたか。

配信を開いたあと、悪い声がどれだけ混じったか。

湊人が数えられるのは、そのくらいだった。

朝の台所には、味噌の匂いが先に立つ。

古民家の土間はまだ冷えていた。

けれど、かまどではなくガス台の上で鍋が温まり、縁側の障子には薄い光が差している。

柱時計は、居間の壁で静かに時を刻んでいた。

正確ではない。

昨日、日下部が「一時間で数分ずれるな」と苦い顔をした時計だ。

それでも、止まっていたものが動いている。

その音だけで、家の中に少しだけ時間が戻ったように感じる。

湊人は鍋をかき混ぜながら、配信用の端末を確認した。

画面には、まだ誰もいない台所が映っている。

手元。

まな板。

湯気。

それだけ。

コトハの白い髪も、小さな角も、端末の外にある。

「熱いぞ」

湊人が言うと、台所の右側で小さく衣擦れがした。

コトハは返事をしない。

けれど、椅子の脚が少しだけ床を鳴らした。

起きている。

腹も減っている。

それだけわかれば、今は十分だった。

戸口から、軽い足音が入ってくる。

「おはよー。……うわ、味噌汁の匂い、だいたい勝ち！」

美月だった。

髪をひとつに結び、薄い上着の袖をまくっている。

畑から来たのか、靴の端に少し土がついていた。

「朝飯、食べてきた？」

湊人が聞くと、美月は目を丸くした。

「聞く？　それ聞く？　ここで味噌汁の匂いさせといて？」

「食べてきたなら、無理に出さない」

「半分食べてきた！」

「半分って何だ」

「じいちゃんの前では食べた顔をした。こっちでは本当に食べる」

湊人は、少しだけ笑った。

「じゃあ、小さい茶碗な」

「やった」

美月は端末の横に座り、コメント管理用の画面を開く。

その動きは、昨日より少し慣れていた。

けれど、目の奥には眠気が残っている。

夜も遅くまで残っていたからだ。

「美月さん、昨日あれから大丈夫だったのか」

「平気平気。じいちゃんなんか、あたしに世話焼かれると年寄り扱いするなって怒るし。早く嫁に行けって言ってくるし」

美月は笑って言った。

明るい言い方だった。

けれど、最後に少しだけ声が落ちた。

「ばあちゃんがいたころは、よくここで一緒にごはん食べてたんだよね」

湊人は鍋を見る。

味噌を溶かす手を、少しだけゆっくりにした。

「じゃあ、今日はその分も食え」

「言い方、雑」

「雑でも飯は出る」

「それは強い」

美月は笑ってから、画面を指で叩いた。

「固定コメント、出すよ」

配信画面の上に、短い文章が置かれる。

――――――――――――――
固定コメント
――――――――――――――

この配信は、古民家の台所と無人販売所の見守り配信です。

場所、個人名、近隣施設、関係性の推測は書かないでください。

行かない。探さない。問い合わせない。写真を撮らない。確かめに来ない。

食べ物と生活を見守る場所です。

あたたかい声だけ、届くようにしてください。

――――――――――――――

湊人は文面を読んだ。

少し強い。

けれど、今はそのくらいでいい。

「堅いな」

「堅くていいの。やわらかく言うと、わからない人は本当にわからない」

「そうだな」

「でも最後は、あたしの趣味」

あたたかい声だけ、届くようにしてください。

その一文を、湊人はもう一度見た。

コトハが画面の外で、かすかに顔を上げる気配がした。

文字が読めるのかはわからない。

言葉の意味を全部わかっているのかも、まだわからない。

ただ、その一文が出た瞬間、台所の空気が少しやわらかくなった気がした。

――――――――――――――
コメント
――――――――――――――

たまご粥：おはようございます

冷凍みかん：固定コメント助かる

地下鉄迷子：行かない探さない、ほんと大事

眠れる作業台：時計の音入ってる？

音だけ勢：入ってる。古い家の朝って感じでいい

灰皿を洗う人：味噌汁の湯気だけで起きた

焼き塩レモン：鍋の火加減、昨日より安定してる

ねむい会社員：仕事行きたくない

縁側ほしい：この配信見ながら靴下履いてる

――――――――――――――

コメントは多すぎない。

けれど、昨日より確かに増えていた。

流れ込むというほどではない。

誰かが誰かを連れてきて、その誰かがまた少しだけ残っている。

その程度の増え方だった。

湊人には、それがかえって怖かった。

大きく燃えるものなら、まだ対処の形が見える。

静かに増えるものは、気づいた時には日常の中へ入り込んでいる。

美月はコメントを見ながら、不要なものを淡々と隠していく。

地名を探る言葉。

近くの店名を出す言葉。

白い髪の子、という単語を含む言葉。

全部を消すわけではない。

けれど、残すべきではない線は、見つけた瞬間に切る。

その手つきは、いつもの明るさとは違っていた。

「慣れてるな」

湊人が言うと、美月は肩をすくめた。

「無人販売所ってね、野菜だけ置いてるわけじゃないんだよ」

「どういう意味だ」

「お金を置く人もいる。持っていくだけの人もいる。余計なことを書く人もいる。でも、ちゃんと見てくれてる人もいる」

美月は画面から目を離さない。

「だから、全部疑うと続かない。全部信じると壊れる」

湊人は返事をしなかった。

鍋の中で、豆腐が小さく揺れている。

味噌の匂い。

柱時計の音。

コメントの流れ。

右側の、映らない場所で聞こえる小さな息。

守るものが増えている。

湊人はそう思った。

増やしたつもりはない。

けれど、飯を作り、配信を開き、無人販売所に野菜を並べた時点で、もう閉じた場所ではなくなっている。

「美月」

「ん」

「危ないと思ったら、すぐ止める」

「うん」

「俺が迷ったら」

美月が顔を上げた。

「その時は、あたしが前に出る」

軽く言った。

けれど、冗談ではなかった。

湊人は、味噌汁を椀によそった。

「前に出るのは、最後でいい」

「最後に出られる人がいるなら、だいたい勝ち」

美月はそう言って、いつもの顔で笑った。

その笑顔に、コトハが少しだけ視線を向ける。

湊人は椀を置いた。

「食べよう」

画面の中では、湯気だけが上がっていた。

その向こうで、コメントがまたひとつ流れる。

――――――――――――――
コメント
――――――――――――――

冷凍みかん：今日も湯気がいい

地下鉄迷子：固定コメント読んだ。了解

ねむい会社員：飯食って出社する

音だけ勢：時計の音、ずれてても好き

――――――――――――――

湊人は、最後のコメントに少しだけ目を止めた。

ずれていても好き。

壊れているものを、すぐ捨てない声。

それが届くなら。

少しだけ、続けてもいいのかもしれない。
