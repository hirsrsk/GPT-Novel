# 権利リスクチェック 人物名と設定

作成日: 2026-05-23

## 前提

このチェックは、既存著作物との混同や連想を避けるための創作上の安全確認である。

法律判断を確定するものではない。

著作権は、原則として名前そのものや単なるアイデアではなく、具体的な創作的表現を保護する。

ただし、著名キャラクター名、作品固有の造語、設定の組み合わせが近い場合は、法的問題以前に読者の混同、編集部の印象、検索上の不利が起きるため避ける。

## 総合判定

現時点の設定全体について、既存作品の具体的な表現を借用している危険は低い。

当初の主人公名「雨宮湊人」は要注意だった。

完全一致ではないが、既存の有名漫画・アニメ『氷の城壁』に主要キャラクター「雨宮湊」が存在し、読みがほぼ同じになる。

作品ジャンル、性格、設定は大きく異なるため、著作権侵害とまでは考えにくい。

しかし主人公名としては検索・読者連想・編集部印象のリスクがあるため、変更を強く推奨した。

対応済み:

- 主人公名を「朝倉湊人」に変更。
- 作中通称「ミナト」は維持。
- 姓を変更したことで、『氷の城壁』の「雨宮湊」との近似リスクを大きく下げた。

## 解消済みリスク

### 旧名: 雨宮湊人

リスク種別:

- 既存著名キャラクターとの近似
- 検索上の混同
- 読者連想

確認内容:

- 『氷の城壁』に「雨宮湊」という主要男性キャラクターがいる。
- 公式アニメサイトにも「雨宮 湊」として掲載されている。
- 旧主人公名「雨宮湊人」は、漢字は一字多いが、姓と読みが近く、作中通称「ミナト」とも重なっていた。

判断:

法的な著作権侵害リスクは高くないが、投稿作品の主人公名としては避ける方がよいと判断。

対応:

- 姓を「朝倉」に変更。
- 新名「朝倉湊人」とした。
- 朝倉湊人については、現時点で著名キャラクターとの強い一致・近似は確認していない。
- Web検索では姓名判断・一般名としての用例は出るが、著名な既存著作物キャラクターとの衝突は見当たらない。

## 中リスク・注意して扱う

### コトハ

リスク種別:

- 一般的な名前、作家名・キャラクター名として使用例が多い

判断:

単体では問題なし。

「無口な神様少女」「白髪」「角」「保護される存在」などの設定全体が既存有名作品に寄りすぎないよう、外見・能力・出自・口調を本作固有のものとして維持する。

### ネクサライブ

リスク種別:

- 企業名・サービス名としてありそうな造語

判断:

現時点で強い既存著名作品名との衝突は見つからない。

ただし「Nexa」「Live」は一般的な語感の組み合わせなので、実在企業やサービスと将来ぶつかる可能性はある。

正式投稿前に再検索する。

### 天城コンツェルン / 天城メディカル

リスク種別:

- 一般姓＋企業語

判断:

強い衝突は見つからない。

「巨大医療企業」「社会インフラ化した悪」という設定はジャンル上よくあるため、天城家の三層構造、呪染症、ダンジョン医療、山主との関係を本作固有にする。

## 設定面のチェック

### 問題が低い理由

本作の中核は以下の複合構造であり、特定の既存作品の設定をそのまま写したものではない。

- 冤罪で探索者ギルドを追放された異世界帰還者
- 田舎の古民家
- 無口な神様少女
- 魔物肉料理による浄化
- 配信の声で存在が安定する
- ざまぁを「生活の湯気による反証」として反転する
- 都会側の大人たちの人間化
- 医療・政治・ギルド・配信産業・地方農業の接続

この組み合わせは本作固有性が高い。

### 注意点

「無口な神様少女」「白髪の少女」「異世界帰還者」「追放ざまぁ」「ダンジョン配信」はジャンル内に類例が多い。

類例が多い要素ほど、具体的な表現で本作らしさを出す。

特に以下を大事にする。

- コトハの言葉少なさは、萌え記号ではなく、声・供物・土地・魔王ネアとの相似性に結びつける。
- 湊人の強さは、戦闘無双ではなく、食べられる形にする技術として見せる。
- ざまぁは、嘲笑ではなく生活の湯気による反証として回収する。
- 配信は承認欲求ではなく、コトハを安定させる声の装置として扱う。

## 推奨対応

1. 主人公名は「朝倉湊人」へ変更済み。
2. 投稿前に「朝倉湊人」の完全一致検索を再度行う。
3. 旧名「雨宮湊人」が本文・設定・章立てに残っていないか定期的に確認する。
4. コトハ、天城、ネクサライブ、魔法派探索者など、主要化する固有名詞は章ごとに再チェックする。
5. 既存作品の画風、台詞、固有設定、キャラクター関係性を意識的に模倣しない。
