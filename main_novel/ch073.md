# 第73話　善意の檻

井坂の端末に届いたのは、天城メディカルからの照会だった。

正式な依頼書ではない。

地域連携窓口から、担当医を通じて回ってきた確認。

添付されていたのは、呪染症患者家族会の要望だった。

署名も、まだ少ない。

それでも、湊人は画面を見た瞬間に嫌な重さを感じた。

文字は軽い。

軽いのに、人の命が乗ると重くなる。

「読むかどうかは、お前が決めろ」

井坂はそう言った。

「中身は」

「患者家族からの声だ。古民家配信と久我山茜の変化を見た人間が、食事支援の可能性を知りたいと」

食事支援。

可能性。

きれいな言葉だ。

湊人は端末に触れなかった。

座敷には、コトハがいる。

今日は丸と線と点の紙を膝に置いていた。

「コトハ」

湊人が呼ぶと、コトハは顔を上げた。

「読む？」

コトハは端末を見た。

文字はまだ全部読めない。

だが、そこに入っている声の重さは感じたのかもしれない。

鉛筆を持ち、紙に点を打った。

まだ。

湊人はうなずいた。

「じゃあ、今は読まない」

井坂は何も言わなかった。

その沈黙がありがたかった。

美月が台所から出てくる。

「それ、読まないと駄目なものですか」

「駄目じゃない」

井坂は答えた。

「ただ、このままなら増える」

「増える」

「眠れない人間がいる。食べられない子どもがいる。久我山茜が眠れたことを知れば、家族は求める」

井坂の声に責める響きはなかった。

だから湊人は、余計に端末から目を離しにくかった。

患者。

食べられない人。

眠れない人。

文面をまだ読んでいないのに、その言葉だけで座敷が少し狭くなる。

コトハは端末を見て、小さく言った。

「いたい人」

「うん」

湊人は答えた。

「いる」

「いる」

「ごはん、いる？」

その問いに、湊人はすぐ答えられなかった。

いる。

必要な人はいる。

でも、必要だという言葉だけで、誰かの台所を開けていいのか。

誰かの身体を測っていいのか。

コトハを可能性として扱っていいのか。

井坂が縁側で低く言った。

「善意は重い」

「はい」

湊人は答えた。

「わかってるやつほど重い」

コトハは丸と線と点の紙を見ている。

丸。

線。

点。

縦線。

小さな印。

選べる形にするための紙。

湊人は、その紙と端末を見比べた。

端末の中には、丸も線も点もない。

ただ、誰かの苦しさだけが入っている。

「湊人」

井坂が言った。

「これは、今すぐ返事をするものじゃない」

「はい」

「ただ、読まないまま消すのも違う」

湊人は端末を見た。

消したい。

そう思った。

自分の台所に、人の痛みを積まれたくない。

コトハの前に、誰かの命を並べられたくない。

でも、消せない。

本当に眠れない人がいる。

本当に食べられない子どもがいる。

湊人は端末を、台所の端ではなく、座敷の棚へ置いた。

「今日は読みません」

「それでいい」

「でも、なかったことにもしません」

コトハが紙に、もう一つ点を打った。

まだ。

今日二つ目の、まだ。

善意は檻になる。

でも、檻にしないために、すぐ答えない人もいる。

湊人は、そこだけは守ろうと思った。
