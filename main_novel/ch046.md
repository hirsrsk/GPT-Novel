# 第46話　古民家の人、怒ってないのに怖い

昼の配信は、湯気だけで始めた。

画面には鍋も映さない。

白い椀と、そこから上がる湯気。

端に少しだけ、木の匙。

それだけだ。

マイクは生きている。

ただし、湊人は話す前に、美月とコトハの位置を確認した。

美月は台所の左奥、コメント管理用の端末の前。

コトハは画角の外、居間の柱の近く。

今日の話は、配信に乗せる。

乗せると決めて、言葉を選ぶ。

「少しだけ、お願いがあります」

湊人が言うと、コメント欄の流れがゆっくりになった。

――――――――――――――
コメント
――――――――――――――

冷凍みかん：声だ

地下鉄迷子：聞きます

たまご粥：固定コメントの件かな

音だけ勢：静かに聞く

――――――――――――――

湊人は、コメントを拾わなかった。

拾うと、言葉がぶれる。

「この配信で映しているのは、食べ物と生活の一部だけです。映していないものは、映さないと決めたものです」

声を荒げない。

怒鳴らない。

責めない。

ただ、線を引く。

「場所を探さないでください。近隣に問い合わせないでください。販売所へ来た場合も、棚以外を撮らないでください。人を撮らないでください。母屋、門の内側、道、車、近隣施設を撮らないでください」

美月の指が、端末の上で止まっている。

今は非表示にするより、聞かせる時間だと判断したのだろう。

湊人は続けた。

「未成年に見える人物について、推測しないでください。名前をつけないでください。探さないでください。心配してくれる人がいることは、わかっています」

そこで一度、息を吸った。

湯気が、白くほどける。

「でも、心配なら何をしてもいいわけではありません」

コメント欄がさらに遅くなった。

誰かが何かを書きかけ、消している気配がある。

「ここは観光地ではありません。答え合わせの場所でもありません。野菜を買う人は、棚を使ってください。配信を見る人は、画面に映っているものだけを見てください」

湊人は、椀の横へ手を置いた。

指先の古い傷が、画面の端に映る。

少しだけ迷った。

映していいのか。

だが、手元はもう、この配信の一部だ。

「誰かを守るふりをして、誰かを怖がらせることは、やめてください」

美月が小さく息をのんだ。

コトハは動かない。

湊人には、彼女が聞いていることだけがわかった。

「ごはんの話は歓迎します。野菜の感想も歓迎します。今日食べたものを書いてくれるのも、ありがたいです。場所や人の話を、台所へ戻してくれる声も、ここでは助かります」

そこで、湊人は初めてコメント欄を見た。

――――――――――――――
コメント
――――――――――――――

地下鉄迷子：場所の話はしません。味噌汁見ます

たまご粥：今日食べたもの書きます。味噌汁です

冷凍みかん：これは怒っていいやつ

音だけ勢：怒ってないのに怖い

灰皿を洗う人：映ってないものを話題にしない

田舎帰りたい：棚は棚。家は家。

――――――――――――――

怒ってないのに怖い。

湊人は、そのコメントに少しだけ目を止めた。

怒っていないわけではない。

怒っている。

ただ、怒りをそのまま出すと、守りたい場所が燃える。

だから、火加減を絞る。

「今日は短く終わります」

湊人は言った。

「飯が冷めるので」

コメント欄に、少しだけ笑いが戻った。

――――――――――――――
コメント
――――――――――――――

ねむい会社員：飯が冷めるなら仕方ない

縁側ほしい：それが一番大事

冷凍みかん：古民家の人、怒ってないのに怖い

たまご粥：でも、ごはん優先なの安心する

――――――――――――――

湊人は、配信を切った。

終了表示を確認する。

カメラオフ。

マイクオフ。

コメント欄停止。

全部を確認してから、美月が背もたれに体を預けた。

「怖かった」

「悪い」

「違う。いい方の怖いやつ」

「いい方の怖いって何だ」

「線を踏んだら戻れないってわかるやつ」

美月はそう言って、少しだけ笑った。

顔色はまだ戻りきっていない。

それでも、笑えた。

コトハが、柱のそばから言った。

「こわい声、すくない」

湊人は振り向く。

「今のは怖くなかったか」

コトハは少し考えた。

「湊人の声、かたい」

「硬いか」

「でも、いたくない」

その言葉で、湊人はようやく息を吐けた。

硬くてもいい。

痛くなければ。

美月が端末を伏せる。

「じゃあ、昼ごはん」

「まだ仕事が」

「飯が冷めるので」

美月は、さっきの湊人の声をまねた。

湊人は少しだけ笑って、椀を三つ並べた。

湯気はまだ残っていた。
