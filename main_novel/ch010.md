# 第10話　名前のない少女

救急車の灯りが坂の下へ消えたあと、古民家には白い蛍光灯と重湯の匂いだけが残った。

少女は湊人の上着を抱え、座布団の上で浅い眠りに落ちている。井坂が診察を続けるあいだ、日下部は駐在所と連絡を取り、身元不明者として必要な照会を進めていた。

服や所持品から身元につながるものは見つからない。少女が倒れていた場所にも、足跡や荷物はなかった。失踪届に似た特徴の子どもも、今のところはいないという。

「呼び名が要ります」

通話を終えた日下部が言った。

「書類なら身元不明女性で通せますが、現場で呼ぶたびにそれでは困る。本人は名を言えませんか」

湊人が声をかけると、少女はゆっくり目を開いた。名前という言葉が伝わっていないらしく、白い瞳は湊人の顔を見たまま動かない。

「覚えていることはあるか」

返事はない。

「どこから来た」

少女の指が上着の布をつかむ。

「帰りたい場所は」

視線がわずかに揺れた。言葉を忘れているのか、答えそのものがないのか、湊人には判断できなかった。

誰かが待っているのなら、本来はその人のもとへ返すべきだ。だが、門の外へ一歩も出られず、呼ぶ名すら持たない少女を、今すぐ返す先はどこにもない。

湊人は名前をつけることにためらいがあった。名を与えれば、自分の側へ置くと決めるように感じられたからだ。

この家でなければ消える。湊人から離れれば弱る。その事実だけでも、少女の選べるものは少なすぎる。そこへ名前まで押しつけたくはなかった。

けれど、日下部の言う通り、呼びかけるたびに少女では済まない。目の前にいる相手へ届く音が必要だった。

口に出せた言葉はまだ少ない。ごはん。おなか。にがい。白い顔を見ているうちに、一つの名が浮かんだ。

「コトハ」

少女が瞬きをした。

「コトハ。嫌なら、別の名前にする」

「……ことは」

初めて聞く音を口の中で転がすように、少女は繰り返した。

湊人が自分ではなく少女を指すと、白い指も同じように胸元へ動いた。

「ことは」

今度は自分を指していた。

日下部が手帳へカタカナで書いた。井坂は名づけに口を挟まず、コトハの顔色を確かめている。

名前がついても体調は変わらない。重湯で呼吸は落ち着いたが、頬は白く、髪先にはまだ畳の色が透けていた。

それでも、湊人が「コトハ」と呼ぶたび、白い瞳はこちらを向く。誰のことを呼んでいるのか、もうわかっている。

「もう少し食べられそうか」

コトハは鍋を見たあと、湊人の荷物へ顔を向けた。古民家へ来てから土間に置いたままの装備袋だった。

鼻先が動く。

「ごはん」

「重湯なら、ここにある」

湊人が小皿を見せても、コトハの視線は装備袋から離れなかった。

異世界から戻って以来、必要な道具だけを詰めて仕事へ持ち歩いていた袋だ。替えの手袋、止血帯、砥石、救急食。事故の日に持ち帰ったまま、中身を確かめていない。

袋を開くと、底から銀色の保存袋が出てきた。探索中の非常食として携帯していた、低級魔物肉の干し肉だった。

ギルドの加工場で毒性と強い瘴気を抜き、人間向けに作られたものだ。味はよくないが、軽く、日持ちがする。

袋の口を開けた途端、コトハは上体を起こした。重湯を見ていた時よりも、はっきりした反応だった。

井坂が肩を支えようとすると、コトハはその手より先に湊人の袖をつかんだ。

「これが食べたいのか」

コトハは保存袋から目を離さない。

「ごはん」

声にも、さっきまでなかった力があった。

日下部の鉛筆が止まり、井坂の顔がさらに苦くなる。

「人間の飯より、そっちに反応するのか」

湊人は袋の中を見た。干し肉は数枚しか残っていない。硬く、塩が強く、そのまま病人へ食べさせられるものではなかった。

「作り直します」

コトハは自分の名を呼ばれた時よりも真剣に、湊人の手元を見ていた。
