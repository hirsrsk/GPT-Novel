# 第3話　門の内側　前半3

「今のは」

「わかりません」

「もう一度」

「やめた方がいい」

湊人の声は、自分でも思ったより低かった。

日下部は湊人を見た。

警官として、止めるべき時の顔をした。

湊人もそれを理解していた。

だから、言葉を足した。

「検証するには、弱りすぎています」

日下部は数秒黙った。

それから、無線機を握り直した。

「井坂先生を急がせろ。状況がおかしい」

おかしい。

たしかに、その一言が一番近かった。

人間なら救急搬送すべきだ。

妖怪か何かなら、警察の仕事ではないのかもしれない。

ダンジョン由来の存在なら、ギルドに連絡するべきかもしれない。

だが、そのギルドから湊人は昨日切られた。

少女の手を握ったまま、湊人は苦く笑いそうになった。

社会から追い出された翌日に、社会の規則からこぼれ落ちた少女を拾う。

悪い冗談だ。

しばらくして、坂道の下から別の足音が聞こえた。

黒い鞄を持った老人が、息を切らしながら上ってくる。

白髪の医者だった。

「日下部、こんな時間に年寄りを山へ呼ぶな」

「先生、文句はあとで聞きます」

「聞く気のない言い方をするな」

井坂はそう言いながら、すでに少女の横に膝をついていた。

その動きに無駄はなかった。

老いているが、医者だった。

脈を取る。

瞼を開く。

首筋に触れる。

胸の音を聞く。

古いペンライトで瞳孔を見る。

そして、眉間の皺が深くなっていく。

「体温が低い。だが、低体温症とは違うな」

「違う？」

日下部が聞いた。

「普通は末端から冷える。だが、この子は体の輪郭だけが冷えているような感じだ。芯がない」

「芯がないって、医学用語ですか」

「わしの感想だ」

井坂は少女の額の角に触れようとして、手前で止めた。

「これは本物か」

「見た感じは」

湊人が答えると、井坂は彼を見た。

「君が通報者か」

「雨宮湊人です」

「雨宮」

井坂はその名前に一瞬反応した。

だが、余計なことは言わなかった。

代わりに、少女と湊人の手を見た。

「その子、君の手を握っているのか」

「はい」

「離すとどうなる」

「呼吸が浅くなります」

井坂は黙った。
